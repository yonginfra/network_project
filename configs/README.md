# 담당 구성의 설정 보관본

`topology2/`에는 본인이 담당한 GRE over IPsec 구성의 라우터·스위치 설정과 터널 주소 메모만 보관했습니다.

비밀번호·VTP 인증값·IKE PSK는 `REPLACE_SECRET_n`으로 대체했습니다. 원본의 약식 명령, 주석·중복·작업 메모는 보존했으며 일괄 실행용 설정은 아닙니다.

장비 적용 전에 [확인·보완 사항](../docs/07-findings.md)과 [점검 순서](../docs/08-runbook.md)를 읽고, 실제 인터페이스·주소·VLAN·Preempt·재분배 정책을 확인합니다.

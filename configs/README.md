# 공개용 컨피그 보관본

원본 작업 메모를 읽기 위한 자료입니다. 모든 파일이 장비에서 추출한 최종 running-config인 것은 아닙니다. 주석·중복·미완성 명령과 모드 전환 누락을 그대로 보존했습니다.

비밀번호, enable secret, VTP 비밀번호, IKE PSK, NHRP 인증 문자열은 REPLACE_SECRET_n으로 대체했습니다. 같은 원본 값은 같은 토큰으로 바꿨습니다. 토큰은 실행용 인증값이 아닙니다.

장비에 적용하기 전 docs/07-findings.md와 docs/08-runbook.md를 읽고 인터페이스·주소·VLAN·Preempt·재분배 정책을 확인합니다. 이번 패키지 작성에서는 설정을 적용하지 않았습니다.

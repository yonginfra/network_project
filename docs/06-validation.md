# 검증 기록과 확인 범위

설정 파일에서 확인한 내용, 당시 발표 기록, 추가 시험이 필요한 항목을 구분했습니다. 이번 문서 수정에서는 장비 실행이나 새 장애 시험을 하지 않았습니다.

| 구분 | 자료에서 확인한 내용 | 해석 범위 |
| --- | --- | --- |
| 내부망 설정 | VLAN·Po12·STP Root·HSRP 우선순위·Track 명령 | 설정 확인. 실제 전환 성공과는 구분 |
| 라우팅 설정 | OSPF·EIGRP 100과 양방향 재분배·태그 필터 | 경로 교환을 위한 설정. 실제 다음 홉·태그 조회 필요 |
| GRE/IPsec 통신 | 해당 구성의 발표 기록에 본사-지사 통신·ESP 관찰 설명 | 당시 기록 기준. 새 SA·카운터 로그는 미포함 |
| Tunnel21 중단·복귀 | 발표 기록의 Tunnel22 우회와 주 경로 복귀 | 해당 터널 시험에 한정. 모든 장애의 무중단을 의미하지 않음 |
| NAT/PAT | Inside/Outside·ACL·pool·overload 설정 | 실제 변환·목적지별 통신은 재시험 필요 |

## 추가로 확인할 시험

1. VLAN별 정상 STP Root, HSRP Active·Standby와 단말 게이트웨이를 기록합니다.
2. 코어 전원 중단과 업링크 중단을 별도 시험으로 나눕니다.
3. Track OR 조건에 따라 한 링크 Down과 두 링크 Down의 결과를 구분합니다.
4. Tunnel21을 중단하고 Tunnel22의 이웃·다음 홉·통신을 확인합니다.
5. 복구 후 우선 경로와 역할의 복귀를 확인합니다.
6. NAT 대상·제외 대상별로 변환과 통신 결과를 확인합니다.

| --- | --- |
| 정상 | Root·HSRP 역할, 라우팅·EIGRP 이웃, 터널·SA, Ping |
| 장애 중 | 대상 장비·인터페이스, 조치 시각, 다음 홉·역할 변화, Ping |
| 복구 후 | 복구 시각, 역할·경로 복귀, 통신 결과 |

전환 시간과 손실률은 같은 시험의 시각·원시 출력·패킷 기록이 있을 때만 수치로 적습니다. 이 저장소에서는 새 성공 로그나 성능 수치를 만들지 않았습니다.

# 설정 확인·보완 사항

아래 내용은 보관한 설정과 발표 자료를 읽으며 구분한 확인점입니다. 장비에서 새로 재현한 장애 결과가 아닙니다.

| 항목 | 보관본에서 확인한 내용 | 추가 확인 |
| --- | --- | --- |
| Tunnel21·22 주소 | 발표 표와 라우터 설정의 일부 주소 차이 | 문서 주소표는 Router-Config와 터널 메모 기준. 재현 시 실행 장비와 비교 |
| VLAN 99 전달 | 코어-액세스 Trunk는 10·20·30·40, 액세스 업링크는 99도 허용 | 관리 VLAN이 필요한 구간의 허용 목록 확인 |
| VLAN 99 HSRP | 코어 주소 .1/.2만 기록 | 업무 VLAN의 VIP .254를 관리 VLAN에도 적용했다고 설명하지 않음 |
| Track 조건 | 두 업링크를 OR로 묶음 | 한 링크 Down과 두 링크 Down을 나눠 시험 |
| NAT pool mask | WAN /30, NAT pool /24 표기 | 장비의 pool 동작과 의도 확인 후 주소 계획 정리 |
| 지사 NAT ACL | 지사 LAN 전체를 표준 ACL로 permit | 지사-본사 트래픽의 실제 변환 여부와 예외 처리 확인 |
| 주소 계획 | 172.168.10.0·172.10.20.0·172.100.30.0 사용 | 실제 환경에 적용할 때 사설 대역으로 재설계 |
| 재분배 주석 | 일부 설명과 tag 100·200 방향이 다르게 읽힘 | 실제 Route Map·다음 홉·태그를 기준으로 확인 |
| 관리·암호 설정 | 과거 실습의 PSK·콘솔·암호 정책 | 운영 적용 전 관리 접속과 암호 정책 재검토 |
| 작업 메모 | 약식 명령, 주석, 중복과 구분선 포함 | 최종 running-config와 대조 후 장비별로 분리 |

원본 설정의 IP와 명령은 임의로 고치지 않았습니다. 이 저장소의 변경은 담당 범위 정리, 설명 문서와 구성도 추가이며, 실제 장비 설정 변경과는 구분합니다.

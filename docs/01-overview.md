# 프로젝트 개요

## 목표와 담당 범위

송용이 담당한 본사-지사 네트워크 구성의 설정과 검증 기록입니다. 본사 내부에는 코어·게이트웨이·상위 연결을 이중화하고, 지사 2곳은 본사 엣지 2대에 각각 GRE over IPsec 터널을 구성했습니다.

한 경로가 끊겼을 때 사용할 대체 경로를 준비하고, 정상·장애·복구 상태에서 역할과 통신 경로를 구분해 확인하는 것이 목표였습니다.

| 항목 | 내용 |
| --- | --- |
| 기간 | 2026.06 - 2026.07 |
| 담당 | 송용 |
| 환경 | GNS3, Cisco IOS |
| 본사 | 코어 2대, 엣지 2대, 액세스 스위치 4대 |
| 지사 | 지사 2곳, 각 지사에서 본사 두 엣지로 터널 구성 |

## 진행 과정

1. 본사·지사 장비와 VLAN·주소 계획을 정리했습니다.
2. VLAN·VTP·Trunk와 코어 간 LACP를 구성했습니다.
3. Rapid PVST+와 HSRP·Track으로 내부 경로와 게이트웨이 역할을 나눴습니다.
4. OSPF와 EIGRP를 연동하고 재분배 경로에 태그 필터를 적용했습니다.
5. GRE over IPsec과 NAT/PAT를 구성했습니다.
6. 터널 장애·복귀 기록과 정상 상태의 점검 항목을 정리했습니다.

## 자료의 범위

이 저장소의 설명은 보관한 설정 파일과 해당 구성의 발표 기록을 기준으로 합니다. 장비를 새로 실행한 결과와 과거 기록을 혼동하지 않도록 [검증 범위](06-validation.md)를 구분했습니다. 실습 당시의 설정 차이와 추가 확인점은 [보완 사항](07-findings.md)에 남겼습니다.
